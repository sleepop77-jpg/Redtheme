Connect your GitHub account to start bridging AI code into repositories.

We need 'repo' scope to create and push commits.
Don't have a token? Here's how:
  1. Go to GitHub Developer Settings.
  2. Name it "PyBridge".
  3. Check the repo box (full control).
  4. Click "Generate token" at the bottom.
  5. Copy and paste it above.
